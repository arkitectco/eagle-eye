# Security

Installing Eagle Eye should leave you exactly as safe as using Claude Code without it. If that stops being true, say so in private. A public issue is the wrong room for this.

If you find a way for a web page, another user or process on the machine, a repository, or an agent to read what the deck holds, or to act through it in a way Claude Code alone wouldn't allow, please report it.

[PRIVACY.md](PRIVACY.md) says what Eagle Eye reads, keeps, and runs, and what stays as it is.

## How to report it

Report it privately, not in a public issue. On the repository's [Security tab](https://github.com/arkitectco/eagle-eye/security), choose Report a vulnerability. Only you and the maintainer see the report until the maintainer publishes an advisory.

Say what you found, how to reproduce it, your Claude Code version and your OS, and where it happened (the terminal, the Desktop app's side pane, or the web page). A short repro beats a long theory.

Prepare for the worst. A quiet report is how we get there.
